# Parametric Pattern Plotter（PPP）

式で描くレザークラフト型紙CAD。寸法を変数と式で書けるパラメトリックな2D CADで、ブラウザで動きます。
`index.html` を1つ開くだけで動きます（インストール不要）。

**▶ ブラウザで使う：https://amber-color.github.io/leather-pattern-cad/**

## できること

- **作図**：角丸矩形・円・直線（折れ線）・ベジェ曲線。グリッドスナップ（0.5 / 1 / 5 mm）
- **ベジェ曲線**：ベジェツールでクリックすると角の点、ドラッグすると曲線の点。頂点のダブルクリックで角⇔曲線の切り替え、線上のダブルクリックで頂点を追加。ハンドルはドラッグで調整（Altで左右を独立）
- **寸法を式で書ける**：`W`、`2*H`、`W+間` のように変数と式で寸法を指定。パスの頂点座標とハンドルにも式が書ける。変数を変えると全パーツが追従
- **ブーリアン演算（非破壊）**：Shift＋クリックで複数選択し、合体・差・交差・排他。元の図形は「材料」として式付きのまま残り、変数を変えると演算結果も作り直される。「確定」で座標を固定、「演算を解除」で元の図形に戻せる。演算結果をさらに演算の材料にすることも可能
- **ステッチ穴の自動配置**：コバ幅・ピッチ・穴径を指定すると、縫い線を内側にオフセットして穴を等間隔に配置。縫い長さが割り切れるようにピッチを微調整
- **画面構成**：右側にパーツ欄と変数バーを横に並べて表示。パーツ欄は図形を選んでいるときだけ出る。変数バーは右上のボタンで折りたためる
- **書き出し**
  - 上部バーの「書き出し」から実行
  - 実寸PDF：用紙（A3・A4・A5・B4・B5・レター、または図形に合わせた1枚）と向き（自動・縦・横）を選んで書き出し。用紙より大きい型紙は自動で分割し、各ページに50mmの確認目盛りと貼り合わせ用トンボ
  - SVG：mm単位、裁断線 / ステッチ穴 / ガイドをグループ分け
  - DXF（R12）：レイヤー `CUT` / `STITCH` / `GUIDE`。角丸はバルジ付きポリラインで正確な円弧。ベジェ曲線はR12に無いため細かい折れ線で出力
  - SVG・PDFではベジェ曲線をそのまま出力
- **保存**：作業中の型紙はブラウザに自動保存。上部バーの「保存」「開く」で `.json` の保存・読み込みも可能

## 使い方

| 操作 | キー |
|---|---|
| 選択・移動 | `V`（Shift＋クリックで複数選択） |
| 範囲選択 | 背景を左ドラッグ（枠に完全に入った図形を選択、Shiftで追加） |
| 角丸矩形 | `R`（Shiftで正方形） |
| 円 | `C` |
| 直線・折れ線 | `L`（クリックで頂点。始点クリックで閉じる、ダブルクリックかEnterで終了、Shiftで水平垂直） |
| ベジェ曲線 | `P`（クリックで角、ドラッグで曲線。終了・閉じ方は折れ線と同じ） |
| 全体表示 | `F` |
| 元に戻す / やり直し | `⌘Z` / `⇧⌘Z` |
| 複製 | `⌘D` |
| 削除 | `Delete` |
| 画面移動 | 右ドラッグ、中ボタンドラッグ、Space＋ドラッグ（タッチ操作は1本指ドラッグ） |
| 拡大縮小 | ホイール |

### 式で使えるもの

`+ - * / ^ ( )`、`sqrt` `abs` `min` `max` `round` `floor` `ceil`、`sin` `cos` `tan` `atan`（度）、`pi`。
変数名には日本語も使えます（例：`コバ = 3`）。
図形や他の変数で使われている変数は削除できず、どこで使われているかが表示されます。

## 印刷の注意

PDFは「実際のサイズ（100%）」で印刷し、下部の50mm目盛りを定規で確認してください。

## 依存

- [clipper-lib](https://www.npmjs.com/package/clipper-lib) 6.4.2（オフセット計算、jsDelivrから読み込み）
