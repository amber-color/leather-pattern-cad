# Parametric Pattern Plotter（PPP）

式で描くレザークラフト型紙CAD。寸法を変数と式で書けるパラメトリックな2D CADです。
`index.html` を1つ開くだけで動きます（インストール不要）。

**▶ ブラウザで使う：https://amber-color.github.io/parametric-pattern-plotter/**

<img src="images/overview.png" alt="サンプル（二つ折り名刺入れ）を開いた画面">

## できること

- **作図**：矩形・円・直線（折れ線）・ベジェ曲線。グリッドスナップ（0.5 / 1 / 5 mm）
- **座標**：CAD と同じく X は右、Y は**上**が正。矩形の X・Y は左下の角。原点に X（赤）・Y（緑）の矢印を表示（書き出しには出ない）
- **パスの位置**：パスにも X・Y があり、頂点はその点からの座標。ドラッグで動かすと X・Y だけが変わる（頂点の式はそのまま）。`外装.右+10` のように式も書ける
- **回転**：矩形・パス・演算結果を回転できます。パネルの「回転（度）」に角度（式も可）を入れるか、選択中の図形の上に出る丸いハンドルをドラッグ（Shiftで15°刻み）。反時計回りが正です
  - 回転中心は「回転中心X・Y」で指定。最初に回したときの図形の中心が自動で入ります。移動すると回転中心もついてきます
  - 回転中心の下の「クリックで指定」を押してキャンバスをクリックすると、その点が回転中心になります（グリッド・図形スナップが効き、ほかの図形の角などにスナップすると参照の式で入ります）。回転済みの図形はその場から動きません。Escでやめる
  - 回転した図形にもステッチ穴・辺ごとの設定・書き出し（SVG・DXF・PDF）がそのまま効きます。回転した矩形はキャンバスの伸縮ハンドルが出ないので、寸法はパネルで編集します
  - 回転した図形への図形スナップは、吸着はしますが数値で入ります（連動しません）
  - 演算結果を回したとき、材料は回転前の位置に表示されます
- **図形スナップ**：作図・移動・ハンドル操作のとき、ほかの図形の点に吸着します。吸着先は水色の印と名前で表示
  - 端点（□）・中点（△）・中心（○）・円の四分点（◇）・交点（×）・線上（⧖）、図形の点と水平・垂直にそろう延長線（点線）
  - 図形の角を持ってドラッグすると、その角を基準に吸着（例：ポケットの右上の角を外装の右上の角に合わせる）
  - ステータスバーの「図形スナップ」か `S` キーで切り替え。`Ctrl` / `⌘` を押している間は一時的に吸着しません
- **連動スナップ**：図形の点に吸着すると、座標が数値ではなく `外装.右` のような**その図形を参照する式**で書き込まれます。参照先の図形が変数で動けば、吸着した図形・寸法線・頂点もついてきます（表示は「端点 · 連動」）
  - 矩形の片側の角だけが吸着したときは、その角に付いたまま大きさを保ちます。両側が吸着すると、その間に張ります
  - 延長線（そろえるだけ）の吸着は参照を作らず、数値になります
  - 参照先の図形を削除しようとすると、どこから参照されているかを表示して止めます。図形の名前を変えると参照も書き換わります

<img src="images/snap.png" alt="矩形ツールで外装の角に吸着し「端点 · 連動」が表示されている" width="560">

- **寸法線**：寸法線ツールで始点と終点をクリックし、線の位置を決めてもう一度クリック。図形の点に吸着すると連動スナップで参照式が入るので、変数で図形が変わっても寸法線が追従する。PDF・SVGでは線と数値を、DXFではDIMレイヤーに線と文字を出力
- **テキスト**：テキストツールでクリックした位置に文字を配置。文字・高さ・回転をパネルで編集でき、位置や高さにも式が書ける。PDFでは日本語もそのまま印刷でき、SVGは文字要素、DXFはTEXTレイヤーに出力
- **矩形の角**：四隅共通、または角ごとに、角丸・面取り・直角をアイコンで選び（角ごとのときは、どの角かも図で表示）、大きさを式で指定。DXFでは角丸を正確な円弧、面取りを直線で出力
- **矩形・円をパスに変換**：パーツ欄の「パスに変換」で、矩形や円を閉じたパスにする。式は残る（右上の頂点は `X+幅` のように書かれる）ので変数を変えても形が追従し、線の上をダブルクリックで頂点を足せる。角丸は頂点の角R、面取りは2つの頂点、円は4つのベジェ曲線の頂点になる。式の中の `自分.…` は元の式に書き直し、ほかの図形からの `X`・`Y`・`直径`・`半径` の参照は `左`・`下`・`幅`・`幅/2` に書き換える
- **ベジェ曲線**：ベジェツールでクリックすると角の点、ドラッグすると曲線の点。頂点のダブルクリックで角⇔曲線の切り替え、線上のダブルクリックで頂点を追加。頂点をクリックで選択（Shiftで追加選択）し、Deleteで削除。ハンドルはドラッグで調整（Altで左右を独立。頂点もハンドルの先もグリッドに吸着）
- **線種と塗り**：パーツ欄の「線種」で、実線・実線（細）・実線（赤）・破線・破線（細）・一点鎖線（シアン）から選ぶ（横に見本）。閉じた図形は「塗り」でハッチング（斜線・逆斜線・綾目・横線・縦線・点）かベタ（薄）を付けられ、間隔（mm、式も可）を指定できる。色は線種の色。左右・上下複製では斜線の向きも反転。書き出しでは線種ごとにグループ・レイヤーが分かれる
- **寸法を式で書ける**：`W`、`2*H`、`W+間` のように変数と式で寸法を指定。パスの頂点座標とハンドルにも式が書ける。変数を変えると全パーツが追従

<img src="images/expressions.png" alt="外装を選んだパネル。幅や高さに変数が入り、変数の欄を開くと計算結果と使用箇所が出る">

- **分割（連動）**：左のツールバーの分割ツール（`K`）。切りたい図形をクリックし、続けて切る線（開いた線）や切る図形をクリックして Enter（先に選んでからツールを押しても可）。線や図形の輪郭に沿って切れ、切れた部分がそれぞれ別の図形（ピース）になる
  - 各ピースは線種・塗りを個別に設定できる。元の図形と切る線は材料として薄く表示され、パーツ欄から選んで編集できる
  - ステッチ穴は演算と同じルール：元の図形か切る線のどれかで「穴を並べる」がオンなら、穴はそれらの設定のまま（分割しても変わらず、ピースでは設定できない）。全部オフなら、ピースごとに設定でき、各ピースの外形に沿って並ぶ。「パスに変換」すると、元の図形の辺ごとの設定をピースの辺に移す（切り口の辺は縫わない）
  - 元の図形や切る線を動かす・変数を変えると、ピースも作り直される（どのピースがどの部分かは位置で覚える）。ピースをドラッグすると元の図形と切る線ごと動く
  - 円などの閉じた図形で切ると、内側と外側（穴あき）に分かれる。線が図形を横切っていないと切れない
  - 「分割を解除」でピースを消して元に戻す。「パスに変換」で折れ線の図形に置き換え、使われなくなった元の図形と切る線は消える
- **フィレット（角を丸める）**：左のツールバーのフィレットツール（`F`）で、平行でない2本の線分を順にクリック。交わっていなくても2本を延長（はみ出していれば切り詰め）して交点でつなぎ、クリックした側を残して半径 R の円弧で角を丸める。R はステータスバーの欄で指定（式も可）。2本目にマウスを乗せると延長線と円弧のプレビューが出る。Esc で選び直し
  - 同じパスの隣り合う2辺：その頂点に角R が付く（パネルの頂点の表の「R」欄で変更・空欄で解除）。SVG・PDF では円弧（ベジェ曲線）のまま出力
  - 同じパスの離れた2辺：2辺を延長してつなぎ、間の辺を消す。実行後にパネルで「別の線として残す」か「消したままにする」を選べる
  - 別々の開いた線（直線・折れ線）2本：延長して1本の線につなぐ
  - 矩形の隣り合う2辺：その角の角R（角ごと）に入る
  - 演算結果・オフセットの隣り合う2辺：その角に角R が付き、パネルの「角R」欄で変更・削除できる。角は位置で覚えるので、変数で形が変わっても同じ角に付いたまま（形が大きく変わって外れたものは「外れ」と表示）
  - 円弧の部分も縫い代・ステッチ穴に反映され、丸めた角の中央で辺が区切られる

Shift＋クリックで複数選択し、合体・差・交差・排他。元の図形は「材料」として式付きのまま残り、変数を変えると演算結果も作り直される。「パスに変換」で座標を固定、「演算を解除」で元の図形に戻せる。演算結果をさらに演算の材料にすることも可能
  - ステッチ穴：材料のどれかで「穴を並べる」がオンなら、穴は材料ごとの設定で決まり、演算結果からは変えられない（材料の穴は演算後もそのまま表示・書き出しされ、演算の名前の横には材料の穴の合計数）。材料がすべてオフなら、演算結果で穴を設定でき、仕上がりの外形に沿って並ぶ。材料はパーツ欄の材料一覧から選んで設定する
  - 「パスに変換」すると、演算結果で設定した穴はそのまま、材料で設定した穴は変換後の外形の各辺に移す（材料の辺に沿った辺は、その辺の設定を引き継ぐ）

<img src="images/boolean.png" alt="内装ポケット：ポケット板から指かけの円を引いた演算結果と、その材料">

- **オフセット（連動）**：左のツールバーのオフセットツール（`O`）で、選んだ図形を外側または内側に指定の距離だけずらした形を作る。図形を選んでからツールを押すとすぐに作成、何も選んでいなければ図形をクリック（Shift＋クリックで複数選んで Enter でも可）
  - パネルで「方向（外側 / 内側）」「距離（式も可）」「角の形（丸く / 尖らせる。既定は丸く）」を設定。角の形は外側では出っ張った角、内側では凹んだ角に効く
  - 複数の図形からは、合体・差・交差・排他の演算をしてからオフセットする（演算はパネルで切り替え。差は1番目の図形から残りを引く）。演算の図形は作らず、元の図形はそのまま残る
  - 元の図形を動かしたり変数を変えたりするとオフセットも作り直される。オフセットをドラッグすると元の図形ごと動く。オフセットに使われている図形は削除できない
  - オフセットにもステッチ穴を並べられ、書き出し（PDF・SVG・DXF）にも出る。円や角丸は細かい折れ線になる。「パスに変換」で今の形の折れ線に置き換えられる（元の図形は残る）

- **ステッチ穴の自動配置**：縫い代（縁から縫い線までの距離）・ピッチ・穴径を指定すると、縫い線を内側にオフセットして穴を配置。ピッチは変えず、角（30°以上の折れ。矩形の角丸・面取りはその中央）で区切った辺ごとに、角に必ず穴を置く
  - 余りの処理：自動（ずれが小さいほう）・詰める（短い間隔を1つ作る）・空ける（長い間隔を1つ作る）
  - 余りの位置：両端（余りを半分ずつ両端へ）・始点・中央・終点
  - 縫い線（点線）をクリックするとその辺を選べて、縫う／縫わない、ピッチ、余りの処理、余りの位置を辺ごとに上書きできる
  - 辺ごとの設定は辺の位置で記憶するので、頂点を足す・角の種類を変える・変数で形を変えるなどしても、同じ辺に付いたまま残る（形が大きく変わってどの辺にも当てはまらなくなった設定は、パネルに件数を表示）
  - 辺の途中を縫わない：辺を選んで「＋ 縫わない区間」を押し、始点からの位置と長さ（mm、式も可）を指定。1つの辺にいくつでも置け、区間の両端には縫い止まりの穴が入る（左右・上下複製では終点からの位置に切り替わり、同じ場所に付く）
  - 辺の一部だけ縫う：「始点から」「終点から」の距離（mm、式も可）で縫う範囲を指定。範囲の端には縫い止まりの穴が入る。キャンバスのハンドルでも調整できる
  - 指定ピッチと違う間隔は赤で表示し、パネルにその寸法と数を表示

<img src="images/stitch.png" alt="外装の上の辺を選んで、辺ごとに縫う範囲や余りの位置を設定しているところ">

- **画面構成**：右側にパーツ欄と変数バーを横に並べて表示。パーツ欄は図形を選んでいるときだけ出る。変数バーは右上のボタンで折りたためる。スマホでは1画面に収まり、上半分が図面、下半分が選んだパーツの欄（何も選んでいないときは変数）になる
- **式の書き方**：変数バーの見出し「変数」にマウスを乗せる（スマホではタップ）と、使える演算・関数・定数・図形の値の一覧が出ます。変数は見出し右の ＋ で追加

<img src="images/mobile.png" alt="スマホでの表示。上半分が図面、下半分が選んだパーツの欄" width="320">

- **書き出し**
  - 上部バーの書き出しアイコンを押して、PDF・SVG・DXFをメニューから選ぶ。どの形式も書き出す前に画面が開き、プレビューを見ながら出力する内容を選べる
  - 出力する内容：線種ごと（実線・実線（細）・実線（赤）・破線・破線（細）・一点鎖線（シアン））・ステッチ穴・縫い線（穴をつなぐ点線）・演算の材料（灰色の破線）・寸法線・テキスト・図形の名前をチェックで選ぶ。最初は今までどおり（縫い線・材料・名前は出さない）。選んだ内容は形式ごとに覚える（例：PDFは全部、DXFは裁断線とステッチ穴だけ）
  - 図形ごと：パーツ欄の「書き出す」を外すと、その図形はどの形式にも出ない。キャンバスでは薄く表示し、名前の横に「（書き出さない）」と出る。型紙に保存されるので、共有した相手にも伝わる
  - 実寸PDF：書き出し前に各ページのプレビューを表示。用紙（A3・A4・A5・B4・B5・レター、または図形に合わせた1枚）と向き（自動・縦・横）を選んで書き出し。用紙より大きい型紙は自動で分割し、各ページに50mmの確認目盛りと貼り合わせ用トンボ
  - SVG：mm単位、線種 / ステッチ穴 / 材料 / 縫い線 / テキスト / 寸法線 / 名前をグループ分け（ハッチングはその図形の線種のグループ）
  - DXF（R12）：線種ごとのレイヤー `SOLID` / `SOLID_THIN` / `SOLID_RED` / `DASH` / `DASH_THIN` / `DASHDOT_CYAN`（破線・一点鎖線は線種付き）とハッチング用の `…_HATCH`、ほかに `STITCH` / `MATERIAL` / `STITCHLINE` / `TEXT` / `DIM` / `NAME`。ベタ塗りは DXF には出ない。角丸はバルジ付きポリラインで正確な円弧。ベジェ曲線はR12に無いため細かい折れ線で出力
  - SVG・PDFではベジェ曲線をそのまま出力

<img src="images/pdf.png" alt="実寸PDFの書き出し画面。用紙と向き、ページのプレビュー" width="420">

- **コード（JSON）で編集**：上部バーの `</>` アイコンで、型紙全体をJSONとして直接編集できます（パーツ欄と変数バーの代わりに右側に開き、スマホでは下半分）
  - 書き換えて「適用」（`⌘Enter` / `Ctrl+Enter`）で図面に反映。`⌘Z` で適用前に戻せます。JSONの誤りや、図形の種類の間違い・IDの重複などがあると適用しません
  - 色分け表示、変数・図形・図形の値（`外装.` のあと）・関数の自動補完（`Ctrl+Space` でも呼び出し）、`"type"` などの決まった値の補完
  - 式の書き間違いは赤、存在しない変数や図形は黄色の印で、書いている途中から表示
  - キャンバスで図形を選ぶと、その図形の行に色が付いてスクロール。書き換えていない間は、図面の変更がコードにも反映されます
  - 開いたとき・適用したとき・読み込み直したときは自動で整形。変数は1行に1つ、図形はキーごとに1行（頂点や辺ごとの設定など短いものは1行にまとめる）
  - 行番号の横の ⌄ で図形ごとに折りたため、畳んだ図形は「外装 · rect …」のように名前と種類を表示。適用や図面の変更で書き直されても畳んだまま
  - CodeMirror の機能：`⌘F` で検索・置換、括弧の対応表示、`Alt` ＋クリックで複数カーソル

<img src="images/code.png" alt="コードパネル。ベロの頂点の式を書き換えている途中で、変数の補完候補が出ている">

- **関係図**：上部バーの関係図アイコンで、変数とパーツのつながりを図にして下に表示します（Grasshopper 風）
  - 左から右へ、値が流れる順に並びます。実線は式で使っている変数、破線は `外装.右` のような図形の参照、点線は材料（演算・オフセット・分割の元）
  - マウスを乗せる（クリックで固定）と、そのノードに関係する上流と下流が光ります。パーツをクリックするとキャンバスでも選択
  - 数値の変数にはスライダーが付き、動かすと図面がその場で変わります。範囲は今の値の半分〜2倍で、離すとその値を中心に取り直します。1回のドラッグが `⌘Z` 1回分
  - ホイールで拡大縮小、ドラッグで移動。✕ で閉じます

- **共有**：上部バーの共有ボタンで、型紙をまるごと埋め込んだURL（`#p=` 以降に圧縮して格納）をクリップボードにコピー。開くとその型紙が読み込まれる（サーバーには何も送らない）
- **日本語 / English**：画面の言語はブラウザの言語設定で自動で決まります。上部バーの文字のアイコンで切り替えられ、選んだ言語を覚えます（切り替えると再読み込みします。型紙は保存されたまま）。使い方（このページ）とサンプルは日本語のままです
- **ライト / ダーク**：上部バーの月・太陽のアイコンで切り替え。最初はOSの設定に従い、切り替えるとその選択を覚えます
- **印刷枠**：上部バーの四隅のかぎ型のアイコン（書き出しの右）で、PDFの用紙と向きで印刷される範囲を図面上に表示
- **パーツ名の表示・非表示**：上部バーのタグのアイコン（印刷枠の右）で、図形の左上に出るパーツ名を隠せます。選択中の図形の名前は隠していても表示。設定はブラウザに保存されます
- **下絵**：上部バーの画像アイコンで写真やスキャンを読み込むと、「下絵」というパーツとして背景に置かれます。ほかの図形と同じく、クリックで選んでドラッグで移動、パーツ欄で X・Y（左下）・幅（式も可。高さは縦横比を保つ）・濃さを編集し、目・鍵・ゴミ箱のアイコンで表示・ロック・削除。何枚でも置けます
  - 「2点で大きさ合わせ」：「実寸」に長さを入れ、画像の上でその2点（例：一緒に写した定規の 0 と 100 mm）をクリックすると実寸に。「点で位置合わせ」：画像の上の点、置きたい場所（スナップが効く）の順にクリック
  - ロック中の下絵の上でドラッグすると範囲選択になります（クリックすれば選べるのでロック解除も可）。作図の目安なので書き出しには出ません
  - 画像は長辺 2000px の JPEG に縮めて、作業中はブラウザ内に保存。上部バーの保存（.json）には画像も入るので、ファイル1つで持ち運べます。共有リンクには入りません
- **表示・非表示とロック**：パーツ欄の目と鍵のアイコンで、パーツを隠したり（書き出しには影響しない）、図形の上で動かしたり消したりできないようにしたり。隠したパーツは画面下の「非表示 n · すべて表示」で戻せます。複数選択中はまとめて切り替え
- **面積**：閉じた図形を選ぶと、パーツ欄に面積（cm² とデシ）。複数選ぶと合計。穴は差し引きます
- **計測**：左のツールの定規（M）で2点をクリックすると、距離・角度・ΔX・ΔY を表示（図形スナップが効く）
- **コピー＆ペースト**：`⌘C` / `⌘V` で、選んだパーツを材料ごとコピー。別の型紙にも貼れ、使っている変数のうち貼り先にないものは一緒に追加されます
- **パネルの大きさ**：パーツ欄・変数バー・コード欄は左端、関係図は上端をドラッグすると幅や高さを変えられます（スマホでは下半分の上端で高さ）。ダブルクリックで元の大きさに戻り、大きさはブラウザに保存されます
- **保存**：作業中の型紙はブラウザに自動保存。上部バーの保存・開くボタンで `.json` の保存・読み込みも可能

## 使い方

| 操作 | キー |
|---|---|
| 選択・移動 | `V`（Shift＋クリックで複数選択。重なっているときは小さい図形・線をクリックした図形が優先され、同じ場所をもう一度クリックすると奥の図形に切り替わる） |
| 式の位置を動かす確認 | 位置が式で決まっているパーツをドラッグで動かすと、離したときに確認が出る（毎回確認。「元に戻す」で取り消し） |
| 範囲選択 | 背景を左ドラッグ（タッチ操作は1本指ドラッグ。枠に完全に入った図形を選択、Shiftで追加） |
| 矩形 | `R`（Shiftで正方形） |
| 円 | `C` |
| 直線・折れ線 | `L`（クリックで頂点。始点クリックで閉じる、ダブルクリックかEnterで終了、Shiftで水平垂直）。描いたあと、開いた線の端の頂点をShift＋ドラッグすると、端の線分の向きのまま延長・短縮（長さはスナップの刻み） |
| 寸法線 | `D`（始点→終点→線の位置の順にクリック） |
| テキスト | `T`（クリックで配置。ダブルクリックで文字を編集） |
| ベジェ曲線 | `P`（クリックで角、ドラッグで曲線。終了・閉じ方は折れ線と同じ） |
| オフセット | `O`（選んでいる図形をすぐオフセット。何も選んでいなければ図形をクリック、Shift＋クリックで複数選んで Enter） |
| 分割 | `K`（切る図形→切る線の順にクリックして Enter） |

| 複製 | `⌘D`。パネル下のアイコン（複製・左右反転・上下反転・削除。マウスを乗せると名前が出る）の左右反転・上下反転で、左右・上下に反転した形を右・下に複製（式は式のまま反転。辺ごとのステッチ設定も反転先の辺に付く） |

| 画面移動 | 右ドラッグ、中ボタンドラッグ、Space＋ドラッグ（タッチ操作は2本指ドラッグ） |
| 拡大縮小 | ホイール（タッチ操作はピンチ） |

### 式で使えるもの

`+ - * / ^ ( )`、`sqrt` `abs` `min` `max` `round` `floor` `ceil`、`sin` `cos` `tan` `atan`（度）、`pi`。
変数名には日本語も使えます（例：`縫い代 = 3`）。数字のあとに文字が続く名前なら、数字で始めても構いません（例：`500円玉直径 = 26.5`）。数字だけの名前、空白や記号（`+ - * / ( )` など）を含む名前、関数名（`sqrt` など）、ほかの変数と同じ名前は使えず、入力中は赤く表示され、欄を離れると元の名前に戻ります。

図形の値も参照できます：`図形名.値`。名前に記号や空白を含む図形は `[内装ポケット（左）].上` のように角かっこで囲みます。

| 値 | 意味 |
|---|---|
| `左` `右` `上` `下` | 外形（バウンディングボックス）の端の座標 |
| `幅` `高さ` `中心X` `中心Y` | 外形の大きさと中心 |
| `X` `Y` | 矩形の左下、テキストの基準点 |
| `直径` `半径` | 円 |
| `点1X` `点1Y` … | パスの頂点（1から数える） |
| `始点X` `終点Y` `長さ` など | 寸法線 |

図形の欄では、その図形自身の値を `自分.値` で使えます（値の名前は上の表と同じ。回転した図形では回転前の値）。
- 角R・縫い代・ピッチ・縫う範囲・回転中心など：`自分.幅/2`（横幅の半分の角R）、`自分.中心X`（回転の中心を常に図形の中心に）
- 寸法どうし：高さに `自分.幅*0.6`（縦横比を固定）、テキストのXに `100-自分.幅/2`（文字幅を測って中央揃え）、頂点に `自分.点1X+20`
- 自分の答えで自分を決める書き方（幅に `自分.幅` など）はエラーになります。演算結果では、角R・ステッチ穴・回転の欄でだけ使えます

値の名前は英語でも書けます（どちらで書いても同じ意味で、保存データも共通）：`left` `right` `top` `bottom` `width` `height` `centerX` `centerY` `diameter` `radius` `startX` `startY` `endX` `endY` `length`、頂点は `pt1X` `pt1Y`、自分は `self`（例：`外装.right+5`、`self.width/2`）。英語の画面では、図形スナップが書き込む式も英語の名前になります。

例：`外装.右+5`、`[ホック（外装）].中心X`、`ベロ.点3Y-外装.上`。
参照は図形の式でだけ使えます（変数の式からは使えません）。参照が循環するとエラーになります。
同じ名前の図形が複数あると参照できないので、名前を変えてください（新しく作った図形には自動で番号が付きます）。
変数パネルの欄にカーソルを置くと、その行が広がって、変数名・式（折り返し表示）・計算結果・使用箇所が表示されます。
図形や他の変数で使われている変数は削除できず、どこで使われているかが表示されます。
